# Google Calendar delivery events — plan

Design: [`../specs/2026-09-02-calendar-design.md`](../specs/2026-09-02-calendar-design.md). Notion task 18.

## Step 1 — the delivery instant reaches the summary

- `CartBuildingService.buildCart` keeps the whole `OfferedSlot` instead of its id.
- `CartSummary` gains `Instant deliverySlotStartsAt`; `getVerifiedCart` takes the slot rather than the
  id string.

## Step 2 — token storage

- `db/changelog/changes/016-google-oauth-token.yaml` — `google_oauth_token`, same shape as
  `mcp_oauth_token`, FK to `users`, deleteCascade.
- `entity/GoogleOAuthToken`, `repository/GoogleOAuthTokenRepository`.

## Step 3 — configuration

`config/GoogleCalendarProperties` (`prefix = "google.calendar"`): `clientId`, `clientSecret`,
`redirectUri`, `authorizationEndpoint`, `tokenEndpoint`, `apiUrl`, `scope`, `calendarId`,
`eventDuration`, plus `configured()`. Defaults in `application.yml` under the `${ENV_VAR:default}`
idiom; `.env.example` and the README get the three variables that matter.

## Step 4 — the clients

- `client/google/GoogleOAuthApiClient` — Feign, form-encoded `/token`, mirroring `SilpoOAuthApiClient`.
- `client/google/GoogleCalendarApiClient` — Feign, `POST /calendars/{calendarId}/events` with an
  `Authorization` header parameter, and the `CalendarEvent` / `EventDateTime` records it posts.

## Step 5 — `service/GoogleAuthService`

`buildAuthorizationUrl(userId)` (opaque state held in memory with a TTL, as Silpo's does),
`completeLogin(code, state)`, `accessToken(userId)` refreshing when within the skew, `isConnected(userId)`.
Nothing logs a token.

## Step 6 — the listener

- `model/OrderConfirmedEvent(userId, orderId, deliveryStartsAt, slotLabel, itemCount)`.
- Published by `CartConfirmationService` and `ReorderConfirmationService` after the row is stored.
- `service/CalendarIntegrationService` — `@Async("applicationTaskExecutor") @EventListener`, three
  early exits, then one insert. Nothing propagates.

## Step 7 — connecting from the chat

- `/calendar` handled in `TelegramRoutingService` before the fallback: a link button, or a plain
  sentence when the integration is unconfigured.
- `controller/GoogleOAuthController` — `/auth/google/callback`, an HTML confirmation, never a token.

## Step 8 — tests

`StubGoogleServer` (token endpoint + events endpoint, recording what it was sent) and
`CalendarIntegrationIntegrationTest`:

1. a connected user gets an event whose start matches the confirmed slot and whose summary names Silpo;
2. an unconnected user gets no call and no error;
3. a confirmed order with no slot start time creates nothing;
4. tokens land in `google_oauth_token` as ciphertext, not plaintext;
5. `/calendar` answers with a consent link;
6. a failing Google API does not affect the confirmed order.

## Step 9 — close out

`make format`, `./gradlew test`, `./gradlew build`, README runbook, commit, Notion (the real-account
smoke test stays unticked), ff-merge into `main`.
